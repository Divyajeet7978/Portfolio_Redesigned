LLM • Graph Analytics

A local workbench that turns plain-English analytics questions about the Olist e-commerce dataset into Cypher, runs them against Neo4j, and currently matches 82 of 112 verified benchmark questions (73%). A local Ollama model writes structured queries from the graph schema; a validator, an EXPLAIN check, and a read-only database account keep every query safe, with one automatic correction attempt on failure.

Bug2JSON

Bug reports to validated JSON

Bug2JSON

LLM Fine-Tuning • Bug Triage

Turns free-text bug reports into schema-validated triage records: category, severity, priority, environment, reproducibility, probable cause, and next step. A FastAPI service and React reviewer UI compare a base Qwen model with a LoRA fine-tune. On a 30-case benchmark the untuned base model returns 100% schema-valid JSON with 0.34 category macro-F1, the baseline the fine-tune has to beat.

Python PyTorch LoRA / PEFT FastAPI React TypeScript

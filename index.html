About me

I'm a software engineer with 3+ years in backend services and data systems. At Vimaan Robotics I write the Cypher and SQL that turn computer-vision scans into live warehouse inventory. Before that, at Cognizant, I built Python and Node.js services and cut PostgreSQL query time by 25%.

I like being able to prove a system works. Olist Query Studio runs every generated query through a read-only account and reports its real benchmark score, and Sort-Downloads has a parity test against the PowerShell script it replaced.

Away from the keyboard I shoot photos and video, read fiction and fantasy, and travel whenever I can.

Olist Query Studio

LLM · Graph analytics

Tools and features

Python, Neo4j, Cypher, Ollama, FastAPI, Streamlit

Turns plain-English analytics questions about the Olist e-commerce dataset into Cypher and runs them against Neo4j. A local Ollama model writes the queries from the graph schema; a validator, an EXPLAIN check and a read-only account keep every query safe.
